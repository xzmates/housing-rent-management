# 租客管理

查询租客列表、查看租客详情和新增租客的能力集合。

## 触发场景

用户原话举例（路由命中本技能）：

- "查一下有哪些租客"
- "看看租客列表"
- "张三的详细信息"
- "新增租客，张三，电话 138..."
- "加个租客，李四"

## 不适用范围

- 房屋查询、合同管理 → 由房屋/合同技能处理
- 删除租客 → 回到小程序页面手动操作

## 接口链路

- `searchTenants`：按关键字和状态搜索租客列表。
- `getTenantDetail`：查看单个租客详情（含名下合同）。

## 使用顺序

- 用户查询租客时优先展示列表。
- 用户选中租客后展示详情。
