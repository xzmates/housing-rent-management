# 需求文档：小程序功能完善（修订版）

## 用户画像
王阿姨，55岁，包租婆，30+套房屋（东楼北、东楼南、里召），部分出租部分空置。不熟悉JSON等技术格式，习惯用语音或自然语言描述。

## 优先级分组

### P0 - 本次必须实现

#### 需求 1：语音/文字导入房屋+租客+缴费
**场景**：王阿姨对着手机说："东楼北101，月租1000，麦粥住的，2023年3月入住，季付，押金2000，最近一次交租是2024年12月"
- 系统解析出：房屋(101, 东楼北, 1000)、租客(麦粥, 入住2023-03, 季付, 押金2000)、缴费(租金, 2024-12, 已缴)
- 一条语音/文字 → 同时创建房屋、租客、缴费记录

#### 需求 2：批量抄水电表
**场景**：王阿姨每月挨家抄表，需要一个页面集中录入
- 显示所有在租房屋列表（编号、租客、上次读数）
- 逐行输入当前读数，自动算费
- 批量提交，生成缴费记录

#### 需求 3：租客详情页
**场景**：查某租客的账，需要看合同、所有缴费、水电记录
- 点击租客 → 进入详情页
- 展示：基本信息 + 合同摘要 + 缴费历史 + 水电记录
- 支持"补录缴费"快捷操作

#### 需求 4：缴费记录导出
**场景**：给会计做账或自己留存
- 按当前筛选条件导出CSV
- 包含：日期、类型、房屋、租客、金额、状态、描述
- 复制到剪贴板

### P1 - 验证现有逻辑

#### 需求 5：现有业务逻辑验证
- 退租结算逻辑（预付租金、押金抵扣、水电费结算）
- 临近收费提醒（逾期检测、10天内到期提醒）
- 租金覆盖预付制（覆盖期限计算、溢出转押金）
- 水电费计算（读数差值 × 单价）

### P2 - 后续迭代

- 收租日自定义（每月固定日）
- 房东信息设置
- 合同分享/打印
- 收费提醒增强（逾期汇总、跳转）
- 数据统计增强（月度收支、空置率）
